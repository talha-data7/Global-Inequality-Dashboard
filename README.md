# 🌍 Global Inequality Dashboard

![Dashboard Screenshot](https://github.com/talha-data7/Global-Inequality-Dashboard/blob/main/Global-Inequality-Dashboard.jpg?raw=true)

## 📌 Project Overview
An interactive data visualization analyzing the relationship between economic wealth (GDP per capita) and quality of life (Healthy Life Expectancy) across 156 countries in 2019. 

## 🛠️ Tech Stack
*   **Python** (Pandas for data loading and manipulation)
*   **Plotly Express** (For interactive, high-quality visualizations)
*   **Google Colab** (Development environment)

## 💡 Key Insights
The data reveals a strong positive correlation between GDP per capita and healthy life expectancy. However, the rate of return diminishes after a certain GDP threshold (~$1.2), showing that beyond a certain point, additional wealth does not guarantee a proportionally longer life expectancy. 

## 🚀 How to Run
1. Open the `Global_Inequality_Analysis.ipynb` file in Google Colab.
2. Upload the `world_happiness.csv` dataset.
3. Run all cells to generate the interactive chart.
